# NeuroAtlas — أطلس الدماغ العصبي السريري والتفاعلي ثلاثي الأبعاد

> **Interactive 3D Clinical Neuroscience & Neuropsychiatric Atlas**  
> منصة سريرية وأكاديمية متقدمة لاستكشاف تشريح الدماغ البشري ثلاثي الأبعاد، الاتصال العصبي الوظيفي (fMRI/DTI)، والأساس العضوي والفيزيائي للاضطرابات النفسية والعصبية.

---

## 🌟 المميزات الرئيسية (Core Features)

### 1. 🧠 المستكشف ثلاثي الأبعاد والاتصال العصبي (3D Brain Explorer & DTI)
- **مجسم ثلاثي أبعاد عالي الدقة** مبني بتقنيات **Three.js** و **React Three Fiber**.
- **المسارات العصبية الحقيقية (DTI Tractography)**:
  - السبيل القشري النخاعي (Corticospinal Tract)
  - الحزمة المقوسة (Arcuate Fasciculus)
  - القوس الحزامي (Cingulum)
  - الإشعاع البصري (Optic Radiation)
  - الجسم الثفني (Corpus Callosum)
  - الإشعاع المهادي القشري (Thalamocortical Projections)
- محاور مقطعية متزامنة (Sagittal, Coronal, Axial) وإحداثيات فضائية معيارية (**MNI-152** و **Talairach**).
- وضع شفافية القشرة (Cortical Translucency) لعزل الهياكل الداخلية والحزم العصبية.

### 2. 🩺 أطلس الاضطرابات النفسية والعصبية والأساس العضوي (Neuropsychiatric Atlas)
ربط تشريحي وعضوي شامل لأكثر من **73 اضطراباً ومتلازمة عصبية-نفسية** عبر 11 تصنيفاً طبياً رئيسياً:
1. **اضطرابات الهوية والوعي والذات** (الهوية الانفصامية، تبدد الشخصية، متلازمة كوتار، كابجراس، اليد الغريبة، الطرف الوهمي).
2. **اضطرابات الإدراك والهلوسة** (الفصام، الذهان الحاد، تشارلز بونيه، أليس في بلاد العجائب).
3. **اضطرابات الذاكرة والزمن** (كورساكوف، فقدان الذاكرة الشامل العابر، التذكر الفائق، وهم ديجافو).
4. **اضطرابات القلق والخوف** (الهلع، كرب ما بعد الصدمة PTSD، القلق العام GAD).
5. **الوسواس والسلوك القهري** (OCD، توريت، هوس نتف الشعر، التخزين القهري).
6. **اضطرابات المزاج والاكتئاب** (الاكتئاب المقاوم، ثنائي القطب I و II، الهوس).
7. **اضطرابات الشخصية والعلاقات** (الشخصية الحدية BPD، النرجسية، السيكوباتية).
8. **اضطرابات السلوك والدوافع** (ADHD، هوس السرقة، هوس إشعال الحرائق، القمار القهري).
9. **اضطرابات الأكل وصورة الجسد** (فقدان الشهية العصبي، الشره، تشوه صورة الجسد BDD).
10. **اضطرابات النوم والأحلام** (شلل النوم/الجاثوم، الأرق الوراثي المميت FFI، النوم القهري).
11. **حالات عصبية نفسية غريبة** (كلوفر-بوسي، غانسر، متلازمة القدس، متلازمة باريس).

*كل اضطراب يتضمن: الجزء الدماغي المتضرر فيزيائياً، باحات برودمان، الأساس الخلوي والكيميائي، المظاهر السريرية، وزر انتقال فوري لعزل الفص في المجسم 3D.*

### 3. 🔬 التشريح السريري والتنظيم الطوبوغرافي (Clinical Anatomy)
- مستعرض تفاعلي لـ **23 تلفيفاً وتلماً دماغياً رئيسياً** (Gyri & Sulci).
- التروية الشريانية والأقاليم الوعائية الكبرى (**ACA, MCA, PCA**).
- الربط الوظيفي ببحات برودمان (**Brodmann Areas 1-52**).

### 4. 📋 أرشيف الحالات السريرية التاريخية (Clinical Cases)
- حالات سريرية حقيقية وتاريخية رائدة (احتشاء الشريان المخي الأوسط MCA، حالة فينياس غيج Phineas Gage، مريض الذاكرة H.M.، متلازمة غيرستمان، متلازمة بالينت).

### 5. 📖 معجم المصطلحات الطبية والعصبية (Medical Glossary)
- محرك بحث متقدم للمصطلحات التشريحية والعصبية باللغات **العربية، الإنجليزية، واللاتينية**.

### 6. ⚡ محرك الفحص والاستدلال السريري (Diagnostic Engine)
- محاكي تشخيصي تفاعلي يحدد التموضع التشريحي المحتمل للآفة الدماغية بناءً على الأعراض العصبية المدخلة.

### 7. 📏 مقاييس التقييم العصبي السريري (Clinical Scales)
- حاسبة تفاعلية معيارية لـ **مقياس غلاسكو للغيبوبة (GCS)**.
- حاسبة تقييم السكتة الدماغية **(NIHSS)** المعتمدة في وحدات العناية المركزة وطوارئ الأعصاب.

### 8. 🎓 دليل الأطباء والباحثين في العلوم العصبية (Research Guide)
- مراجع الأطالس المكانية (Talairach و MNI-152)، معايير fMRI/DTI، وأدلة النشر الأكاديمي.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 19, Vite
- **3D Engine**: Three.js, React Three Fiber (`@react-three/fiber`), React Three Drei (`@react-three/drei`)
- **Styling**: Tailwind CSS (Dark Clinical Workstation Theme)
- **Typography & Icons**: Google Fonts (IBM Plex Sans Arabic, Google Material Symbols)

## 🚀 التشغيل والتثبيت المحلي (Getting Started)

### المتطلبات (Prerequisites)
- [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)
- npm أو yarn أو pnpm

### خطوات التثبيت:

```bash
# 1. استنساخ المستودع
git clone https://github.com/qusay13/neuroatlas.git

# 2. الانتقال إلى مجلد المشروع
cd neuroatlas

# 3. تثبيت الاعتماديات
npm install

# 4. تشغيل خادم التطوير المحلي
npm run dev
```

افتح المتصفح وتوجه إلى `http://localhost:5173` لاستكشاف المنصة.
